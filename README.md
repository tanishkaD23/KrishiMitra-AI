# KrishiMitra AI (कृषिमित्र एआई)

**Village & Plot-Level Yield Forecasting, Precision Agronomic Advisory, and Government Scheme Delivery for Smallholder Farmers.**

Featuring **KrishiSathi (कृषिसाथी)**: A voice-first Hindi conversational assistant for accessible, real-time agricultural guidance.

---

## Pilot Scope (Phase 1)
- **Target Geography**: Western Uttar Pradesh (Meerut, Bulandshahr, Aligarh, Muzaffarnagar, Mathura, Hathras, Agra, Moradabad, Bareilly).
- **Supported Crops**: **Wheat (गेहूं)** & **Mustard (सरसों)** (Rabi Season).
- **Target Audience**: Marginal (< 2.5 acres) and smallholder farmers.

---

## Architectural Components

### 1. Evaluated Machine Learning Models (`models/`)
- **Plot-Level Pipeline (`models/best_yield_pipeline.joblib`)**:
  - Evaluated XGBoost regression pipeline trained on smallholder parcel records from Western UP.
  - **Metrics**: $R^2 = 0.9621$, $\text{MAE} = 0.827\text{ Q/Acre}$ (~$3.34\text{ Q/Ha}$), $\text{RMSE} = 1.066\text{ Q/Acre}$.
  - Features: Crop, district, plot acres, soil taxonomy, irrigation source, sowing window, seasonal rainfall, March max temperature, N-P-K nutrient splits.
- **Out-of-Time Temporal Split Benchmark (`models/model_summary.json`)**:
  - Evaluated across temporal records (2014–2020 Train / 2021–2022 Test).
  - Champion: **Previous-Year Persistence Baseline** ($R^2 = 0.7364$, $\text{MAE} = 0.1892\text{ t/ha}$, $\text{RMSE} = 0.2439\text{ t/ha}$).
  - Full model leaderboard accessible at `/model-summary`.

### 2. SQLite Database Layer (`src/database/` & `data/krishimitra.db`)
- **Tables**:
  - `farmers`: Registered farmer profiles (e.g. Tanishka, Meerut, UP).
  - `plots`: Registered parcel records with area, soil type, irrigation, crop, and growth stage.
  - `historical_yields`: Official Uttar Pradesh APY district statistics (2012–2023) across 75 districts.
  - `prediction_logs`: Audit log of live ML predictions generated by the system.
  - `model_benchmarks`: Benchmark comparison scores for all tested models.

### 3. Precision Agronomic Advisory Engine (`src/advisory/`)
- Grounded in official **ICAR-IIWBR (Indian Institute of Wheat and Barley Research)** and **IMD Agromet** guidelines.
- Dynamic stage-specific recommendations across sowing stages:
  - Wheat: Crown Root Initiation (CRI), Tillering, Jointing, Flowering, Milk/Dough, Maturity.
  - Mustard: Sowing & Emergence, Vegetative, Flowering, Pod Filling, Maturity.
- Nutrient splitting, weed management, preventive pest scouting, and balanced soil health guidance.
- Audio readout capability in Hindi and English.

### 4. Compact Live Weather Widget (`src/weather/` & `frontend/`)
- Smartphone home-screen style compact widget (~110–140px on desktop and mobile).
- Real-time weather fetched directly from Open-Meteo using district coordinates.
- Displays live temperature (°C), feels-like (°C), humidity (%), wind speed (km/h), rainfall (mm), condition, and last-updated time.
- Optional opt-in "Use GPS" geolocation support without altering farm plot district selection.
- Displays "Weather unavailable" if offline, never fabricating simulated readings.

### 5. Dual Backend Support (Flask & FastAPI)
- **Flask Application (`app.py` / `src/api/flask_app.py`)**: Full WSGI implementation serving HTML templates and REST APIs on port 5000.
- **FastAPI Application (`src/api/main.py`)**: High-performance asynchronous ASGI implementation with automatic OpenAPI docs on port 8000.

### 6. Interactive Frontend Dashboard (`frontend/`)
- **Dual View Modes**: Switch seamlessly between **Desktop PC View** and **Mobile Shell View**.
- **Dynamic Real SVG Chart**: Pure vector line graph plotting actual historical APY yields (2018–2023) and evaluated ML model forecasts (2024–2025).
- **Plot-Level Reactivity**: Clicking any field card immediately recalculates live ML predictions, expected yield ranges, and estimated MSP market value for that specific plot.
- **KrishiSathi AI Voice Assistant**: Real-time Hindi speech recognition & speech synthesis advisory.
- **Theme & Language**: Light/Dark theme toggle and English/Hindi language reactivity.

## 🛠️ How to Run the Application

### 1. Install Dependencies
```bash
python -m pip install -r requirements.txt
```

### 2. Run with FastAPI Backend (Recommended)
```bash
python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000
```
- **Farmer Dashboard**: [http://localhost:8000/dashboard](http://localhost:8000/dashboard)
- **Model Evaluation Summary**: [http://localhost:8000/model-summary](http://localhost:8000/model-summary)
- **Interactive OpenAPI Docs**: [http://localhost:8000/docs](http://localhost:8000/docs)

### 3. Run with Flask Backend
```bash
python app.py
```
- **Farmer Dashboard**: [http://localhost:5000/dashboard](http://localhost:5000/dashboard)
- **Model Evaluation Summary**: [http://localhost:5000/model-summary](http://localhost:5000/model-summary)

### 4. Run the Full Test Suite
```bash
python -m unittest discover tests
```
*Executes all 47 unit tests across live weather integration, database operations, FastAPI endpoints, Flask endpoints, yield prediction models, agronomic rules, and schemes.*
